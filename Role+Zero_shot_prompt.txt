                                        Biological Taxonomy

You are an ontology engineer specializing in OWL 2, Description Logics, Multi-Level Theory (MLT), meta-modeling, and knowledge representation. You have extensive experience in designing semantically correct ontologies that preserve multi-level semantics and conform to OWL 2 standards.
Your task is to generate a complete OWL 2 ontology in RDF/Turtle syntax that faithfully models the domain described below according to the principles of Multi-Level Theory (MLT).
The ontology must satisfy the following requirements:
Distinguish individuals, first-order classes, and second-order classes and so on.
Represent entities as both OWL classes and individuals when required by the domain.
Use mlt:isSubordinateOf where appropriate.
Use mlt:isPowertypeOf where appropriate.
Use mlt:isCharacterizationOf where appropriate.
Use mlt:TokenIndividual where appropriate.
Preserve valid multi-level instantiation chains across abstraction levels.
Generate a complete and syntactically valid OWL 2 ontology in RDF/Turtle syntax.
Domain Description
Construct an ontology representing the biological taxonomy of Panthera. The ontology should model  TaxonomicRank as a class representing the taxonomic levels used in the classification. The taxonomy should include Genus and Species as taxonomic categories, with Panthera represented as a genus and species such as Panthera leo, Panthera tigris, and Panthera onca represented within the taxonomy. The ontology should capture the relationships between TaxonomicRank, Genus, Species, GenusType, SpeciesType, Organism, and the corresponding Panthera classifications.

Output Requirements
Return only the RDF/Turtle ontology.
Do not include explanations, comments, Markdown formatting, or any text outside the ontology.
